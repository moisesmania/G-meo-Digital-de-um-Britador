# G-meo-Digital-de-um-Britador
Construir o gêmeo digital de um ativo ou ambiente de uma operação de mineração e usá-lo para monitorar, em tempo real e historicamente, o que acontece e qual o impacto operacional ou econômico. O foco é duplo: percorrer toda a pilha de IoT entendendo o papel de cada componente, e telemetria em visualizações que respondam a perguntas reais.
